# 项目结构（Android）

一句话：**单 Activity + Compose**，`ui/` 一个屏一个包（Screen + ViewModel），
`data/` 管网络与会话，**没有本地数据库**——书架/进度全部来自服务端，本机只存偏好与登录态。

## 顶层

```
fakenews-comics-android/
├── app/                       应用模块（唯一会打进 APK 的模块）
├── baselineprofile/           Baseline Profile 采集模块（benchmark 变体，不进 release）
├── docs/                      出包与升级、画质增强方案
├── tools/                     模拟器验收脚本（走查 / 出图 / 帧耗时）
├── gradle/wrapper/            Gradle 8.9（wrapper 已入库，不需要预装 Gradle）
├── gradlew / gradlew.bat      构建入口
├── key.properties.example     签名属性模板（真值放 ~/.gradle/gradle.properties）
└── README.md                  构建、签名、模拟器联调
```

```

    │                     Layout（宽屏判定与断点）/ BackToTop / Format / Time
    ├── boot/             冷启动海报页（等服务器就绪）
    ├── setup/            首次连接服务器
    ├── login/            登录（服务端开启门禁时）
    ├── home/             首页：继续阅读 + 筛选 + 网格（无限滚动）
    ├── shelf/            书架：收藏 / 阅读记录
    ├── search/           搜索
    ├── libraries/        漫画库：列表 / 新建与编辑（LibraryFormSheet）/ 目录点选（DirPickerSheet）/ 上传（UploadSheet）
    ├── detail/           详情：封面 + 元信息 + 编辑（DetailEditSheet）+ 章节
    ├── reader/           阅读器：ReaderScreen + 四种翻页（ReaderStages）+ 手势（ReaderGestures）+
    │                     PagerMode（双页对开规则）+ 设置弹层
```

## 启动与一次阅读的路径

**启动**：单 Activity（`MainActivity`）→ `ui/AppNav.kt` 的 NavHost，起点 `BOOT`：
`BootScreen` 用 `data/session/ServerStore.kt` 存的地址与会话试连 `/api/health`——
没配过 → `SETUP`（填服务器地址）；连上但 401 → `LOGIN`；都好 → `MAIN`（五 tab）。
所有请求经 `data/net/ApiRunner` 统一附带会话 Cookie 与动态地址。

**一次阅读**：`/api/comics` 列表 → `/api/comics/{id}` 详情与章 →
`/api/comics/{id}/chapters/{ch}/pages/{i}` 逐页取图（Coil 磁盘缓存，本机没有库表）；
翻页停手防抖上报 `PUT /api/progress`，退出/切章强制上报。

## 按任务找文件

| 想改什么 | 去哪儿 |
|---|---|
| 加一个接口调用 | `data/net/FakenewsApi.kt` 加方法，DTO 放 `data/model/`，ViewModel 里用 `ApiRunner` 调 |
| 接口字段变了 | `data/model/` 的 DTO（字段名必须和 server JSON 完全一致）+ 对应 `*Test.kt` |
| 新加一个页面 | `ui/<屏>/` 建 `XxxScreen.kt` + `XxxViewModel.kt`，在 `MainActivity` 的导航表里挂上 |
| 改视觉（颜色/圆角/字重） | `ui/theme/Theme.kt` + `ui/common/` 里的基础组件 |
| 改翻页动效 | `ui/reader/ReaderStages.kt`（分模式）+ `ui/reader/ReaderGestures.kt`（手势）+ `ui/common/Motion.kt`（曲线） |
| 双页排布规则 | `ui/reader/PagerMode.kt`（规则来自服务端仓库 `app/web/src/utils/pagerMode.ts`） |
| 阅读进度上报 | `ui/reader/ReaderViewModel.kt`（停手防抖 + 退出/切章强制上报） |
| 偏好项（新增一项设置） | `data/session/*Prefs.kt` + `ui/settings/SettingsScreen.kt` |
| 上传相关 | `data/upload/LibraryUploader.kt`（长超时客户端、进度回调） |
| 出包 / 签名 | `README.md` + `docs/出包与升级.md` |

## 几条容易踩的硬约束

- **图片重采样**：Compose 的 `FilterQuality` 在 Android 上只区分「过滤 / 不过滤」，
  Low/Medium/High 逐像素相同；想要更好的缩放只能自绘 + AGSL(33+) 或 native。
  结论与实测数据见 [`docs/画质增强方案.md`](画质增强方案.md)。
- **提示用 `AppToast`**（自绘，`ToastCenter.show()` 的返回值就是撤销契约），不要用 M3 SnackbarHost。
- **上传必须用独立的长超时客户端**：共享 OkHttp 是 read 60s / write 30s，而服务端还要解压，
  所以 `LibraryUploader` 用 `newBuilder()` 派生（顺带继承 CookieJar 与动态地址拦截器）。
- **库增删改要发 `ComicEvents.LibraryChanged`**：删库不会触发扫描，别的页的快照不会被自动纠正。
- **拖动手势的起始位置不能存在跨手势变量里**：松手后的零位移 delta 会把位置写回上次终点，
  位移逐次累加（轻拖就翻页、方向读反）。用「基准 + 本次累加」并在首个 delta 自愈重取。
- **宽度/列数判定用 `BoxWithConstraints` 的 `maxWidth`**，不要用 `LocalConfiguration.screenWidthDp`
  （Activity 声明了 configChanges，Configuration 比布局晚一整轮）。
- 一个 screen 只挂一个 `LazyVerticalGrid` / `LazyColumn`；骨架屏不能嵌在另一个 Lazy 容器里。
